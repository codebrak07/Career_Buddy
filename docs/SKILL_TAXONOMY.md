# Skill Taxonomy — Standardized Competency Graph

## 1. Domains & Categories

The system categorizes 50+ standardized skills across 6 primary engineering domains:

1. **Foundations (`fundamentals`)**:
   - `prog-foundations`: Variables, control flow, loops, functions
   - `data-structures`: Arrays, trees, graphs, hash maps, complexity analysis
   - `math-stats`: Probability, linear algebra, hypothesis testing, distributions
   - `git-vcs`: Version control, branching, PR workflows, merging

2. **Frontend Engineering (`frontend`)**:
   - `html-css`: Semantic markup, flexbox, CSS grid, responsiveness
   - `javascript-core`: ES6+, closures, async/await, DOM APIs
   - `typescript`: Static typing, interfaces, generics, type narrowing
   - `react-core`: Components, hooks, state management, virtual DOM
   - `nextjs-fullstack`: SSR, SSG, App Router, server actions, caching
   - `tailwind-css`: Utility-first styling, design token systems

3. **Backend Engineering (`backend`)**:
   - `python-core`: OOP, generators, decorators, package management
   - `nodejs-backend`: Event loop, Express/Fastify, REST API design
   - `relational-sql`: PostgreSQL, MySQL, indexing, normalization, joins
   - `nosql-databases`: MongoDB, Redis caching, key-value stores
   - `system-design`: Microservices, load balancing, caching, message queues
   - `fastapi-apis`: Async Python, Pydantic schemas, OpenAPI docs

4. **Data & Machine Learning (`data_ml`)**:
   - `numpy-pandas`: Vectorized manipulation, data cleaning, aggregation
   - `exploratory-analytics`: EDA, feature correlation, outlier detection
   - `bi-visualization`: Power BI, Tableau, Metabase dashboards
   - `ml-algorithms`: Scikit-learn, regression, random forests, clustering
   - `deep-learning`: PyTorch, TensorFlow, CNNs, Transformers
   - `mlops-deployment`: MLflow, Model registry, containerized inference

5. **DevOps & Cloud Infrastructure (`devops_cloud`)**:
   - `linux-shell`: Bash scripting, process management, permissions
   - `docker-containers`: Dockerfiles, multi-stage builds, compose
   - `kubernetes-k8s`: Pods, deployments, services, ingress controllers
   - `aws-cloud`: EC2, S3, Lambda, IAM, CloudFront
   - `cicd-pipelines`: GitHub Actions, automated testing, deployment pipelines

6. **Professional & Product (`soft_skills`)**:
   - `technical-writing`: RFCs, API documentation, README dossiers
   - `agile-scrum`: Sprint planning, sprint retrospectives, estimation
