# Product Vision — Career Intelligence Instrument

## The Core Philosophy: Evidence-Aware Career Intelligence

Most career advice systems treat student resumes as bags of words. If a resume mentions "Python", an AI chatbot enthusiastically declares the student ready to build autonomous machine learning systems.

This creates a catastrophic disconnect between learner perception and market reality:
1. **The Inflation Trap**: Students apply for senior roles they are unprepared for and face silent rejections.
2. **The Ambiguity Void**: Students know they are missing "something", but cannot tell if they lack language fundamentals, architectural patterns, or production deployment skills.
3. **The Unverifiable Claim**: Employers discount resumes because claimed skills have no proof of work attached.

### The Antidote: The Career Intelligence Instrument

Our platform is engineered around a simple, unbreakable premise:

> **Skill without evidence is merely a hypothesis. Readiness is the sum of verifiable competency.**

```text
Raw Artifacts (Code, Coursework, Certs)
              ↓
    Epistemic Classification (Claimed → Detected → Evidenced → Validated)
              ↓
    Deterministic Role Match Engine (Coverage + Strength + Prereqs - Blockers)
              ↓
    Categorized Outcomes (Ready Now vs Reachable)
              ↓
    Topological Gap Path (Ordered Dependencies)
              ↓
    Targeted Validation Assessment
              ↓
    Real-Time Recalibration
```

## The Ten Commandments of This Product

1. **Never conflate participation with mastery**: Completing a video tutorial is a 0.2 strength signal. Passing a timed algorithmic test with 90% is a 0.8 strength signal.
2. **Deterministic authority over probabilistic suggestion**: An LLM should extract terms and write prose; a mathematical formula must score career readiness.
3. **Prerequisites must dictate learning order**: Never tell a user to learn Kubernetes before they understand containers and basic networking.
4. **Reachable is not failure**: Separating "Ready Now" from "Reachable" protects the candidate's confidence while charting an honest roadmap.
5. **No unexplained numbers**: Every percentage shown to the user must expand into its exact formula components.
6. **Calibrated uncertainty**: If a user submits only 2 course names, the system reports "Insufficient Evidence (High Uncertainty)", not a fake 95% match.
7. **Curated truth before real-time noise**: Use structured labor-demand reference datasets with transparent source attribution.
8. **Actionable gap resolution**: Every identified blocker must link to a specific learning resource and a demonstrable project goal.
9. **Instant recalculation**: The moment a user submits proof (e.g., completes an assessment), their readiness meters must update immediately.
10. **Aesthetic rigor as respect**: The UI is a professional telemetry instrument — high density, crisp typography, restrained elegance, zero gimmickry.
